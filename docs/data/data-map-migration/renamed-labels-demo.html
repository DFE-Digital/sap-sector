KS4 performance · School pupil groups

When DfE renamed two pupil groups, a year of school figures went blank

The KS4 school performance tables label each row with a pupil group. Between 2023-24 and 2024-25, DfE changed the wording for two groups. The data map asked for one wording for both years, so one year of each group matched nothing, and every school’s figure came out blank.

The data map used one label per group for both years. Each label only exists in one year’s file, so each group lost one year: EAL for 2024 to 2025, not disadvantaged for 2023 to 2024.

Step 3 · How it was found

The new checks compare the data map with the real files

Nobody reported it, because no page shows these groups yet. It was found automatically: the data map validation compares every filter value with the values that actually occur in each source file, and reported:

[unknown-value] KS4_Performance/Establishment.Attainment8_EAL_Est_Current_Num: filter breakdown = 'Other than English' matches no rows in 202425_performance_tables_schools_final
[unknown-value] KS4_Performance/Establishment.Attainment8_NDi_Est_Previous_Num: filter breakdown = 'Not known to be disadvantaged' matches no rows in 202324_performance_tables_schools_final
Step 4 · The fix

Each year’s file now uses its own wording

In the code-based data map, the school performance tables source takes each year’s labels, so the difference is written down in one place instead of being lost across hundreds of spreadsheet rows.

// Ks4Performance.cs
var schoolsCurrent = PerformanceTables("202425_performance_tables_schools_final", Current,
    eal: "Known or believed to be other than English", notDisadvantaged: "Not known to be disadvantaged");
var schoolsPrevious = PerformanceTables("202324_performance_tables_schools_final", Previous,
    eal: "Other than English", notDisadvantaged: "Disadvantaged all other");
Step 5 · Stopping it happening again

The same kind of change is now caught before it reaches the website

  1. On every pull request: the data map is checked against a snapshot of every source file, so a wrong label fails the build.
  2. On every pipeline run: the files just downloaded are checked before anything is loaded. If DfE renames a group, column or year in a new release (such as the 15 October KS4 data), the run stops and the website keeps its previous figures.
  3. On a new data year: the runbook’s dry run lists every label and column the new files no longer have, so the change can be fixed before release day.

Impact

  • Not visible today: the KS4 pages dont yet offer a pupil-group filter, so users havent seen these blanks. They would have appeared as soon as one was added.
  • Now: about 5,700 schools have values for each of the two affected group-years, which is the full set of schools in those files.
